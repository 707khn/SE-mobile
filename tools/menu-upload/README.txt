ЗАГРУЗКА МЕНЮ СТОЛОВОЙ В ПРИЛОЖЕНИЕ
====================================

Что это
-------
Маленькая программа для компьютера с 1С. Берёт файл меню, выгруженный из 1С в
Excel, и отправляет его в приложение. Устанавливать ничего не нужно — всё
работает на встроенном в Windows PowerShell.

Ярлыка два, программа одна:

   «Меню на сегодня»  — обычная работа изо дня в день. Меню из файла
                        встаёт на сегодняшнее число, что бы за дату ни
                        проставила 1С.

   «Загрузить меню»   — когда даты берутся из файла: например, в выгрузке
                        сразу вся неделя.


Установка (один раз)
--------------------
1. Скопируйте всю эту папку в свои «Документы»:

      C:\Users\<ваше имя>\Documents\Загрузка меню

   Именно туда, а не в корень диска: в C:\ обычному пользователю писать
   не разрешают, и программа не сможет вести журнал. Прав администратора
   для установки не нужно — ни здесь, ни дальше.

2. Откройте settings.txt Блокнотом и проверьте:
      server   — адрес сервера (обычно менять не нужно)
      login    — логин технолога столовой, тот же, что в приложении
      password — пароль

   Необязательно:
      folder   — папка, куда 1С выгружает меню. Если указать, окно выбора
                 файла будет сразу открываться в ней.

3. Сделайте ярлыки на рабочем столе — правой кнопкой по файлу →
   «Отправить» → «Рабочий стол (создать ярлык)»:

      «Меню на сегодня.bat»  — понадобится каждый день
      «Загрузить меню.bat»   — понадобится изредка


Как пользоваться
----------------
После выгрузки меню из 1С — одно действие:

   перетащите файл Excel на ярлык «Меню на сегодня»

Либо запустите ярлык двойным щелчком и выберите файл в открывшемся окне.

Через несколько секунд появится сообщение, например:

   Загружено:
   19.08.2026 — 12 блюд (Супы 3, Вторые блюда 5, Напитки 4)

Дата в сообщении — всегда сегодняшняя: меню ставится на сегодня, даже если
1С проставила в файле другое число или не проставила никакого. Проверьте по
сообщению, что всё распозналось верно. Меню сразу видно в приложении в
разделе «Меню».

Если в выгрузке сразу несколько дней — «Меню на сегодня» так и скажет и
загружать не станет: какой из дней сегодняшний, программе не решить. Для
таких файлов есть второй ярлык, «Загрузить меню»: он раскладывает дни по
датам из файла.


Что важно знать
---------------
• Повторная загрузка того же дня заменяет меню целиком, а не добавляет второй
  раз. Ошиблись файлом — просто загрузите правильный.

• Если в файле несколько дат, «Загрузить меню» запишет каждый день отдельно.

• Разделы («Супы», «Вторые блюда», «Напитки») берутся из строк без цены.
  Если в выгрузке разделов нет, все блюда попадут в раздел «Блюда».

• Поправить отдельное блюдо можно прямо в приложении: «Меню» → значок
  календаря с карандашом.

• Первая загрузка за день может идти до минуты — сервер «просыпается».


Если прав администратора нет
----------------------------
И не нужно. Программа ничего не устанавливает в систему: она работает на
PowerShell, который в Windows уже есть, и пишет только в свою папку.
Загружать меню разрешено технологу столовой по её обычному логину —
отдельная учётная запись не нужна.

Единственное, что может потребовать администратора, — не сама программа,
а сеть. Проверьте одной командой (права для неё не нужны):

   nslookup api.se-btrz.com

   87.199.130.179          — всё в порядке, ставьте и пользуйтесь.
   Non-existent domain     — компьютер не знает адреса сервера. Это чинится
                             записью в DNS предприятия, см. deploy/README.md,
                             шаг 4. Своими силами обойти нельзя.

Если при запуске появляется сообщение о запрете выполнения сценариев —
значит скрипты закрыты групповой политикой предприятия. Программа
запускается с ключом, который обходит обычный запрет, но политику домена
он не перебивает. Это тоже к тем, кто ведёт сеть.


Если что-то пошло не так
------------------------
Рядом со скриптом ведётся журнал upload_log.txt — в него пишется каждый
запуск: какой файл, какой адрес, что ответил сервер, текст ошибки.
Откройте его в первую очередь.

Если окно вообще не появилось, запустите вручную и посмотрите сообщение:

   1. Откройте папку со скриптом
   2. Зажмите Shift, правой кнопкой в пустом месте -> "Открыть окно
      PowerShell здесь"
   3. Выполните:
        powershell -ExecutionPolicy Bypass -File .\upload_menu.ps1

Программа показывает причину прямо в окне:

  «Неверный логин или пароль» — проверьте settings.txt.

  «Загружать меню может технолог столовой» — указан чужой логин.

  «В файле не найдено ни одного блюда» — скорее всего выбран не тот файл,
  либо 1С изменила разметку выгрузки. Пришлите этот файл разработчику,
  разбор поправят на сервере — программу на вашем компьютере обновлять
  не придётся.
