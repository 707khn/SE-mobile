МЕНЮ СТОЛОВОЙ: ЗАГРУЗКА И ВЫГРУЗКА
===================================

Что это
-------
Две маленькие программы для компьютера с 1С. Устанавливать ничего не нужно —
всё работает на встроенном в Windows PowerShell.

   «Загрузить меню»  — берёт файл меню, выгруженный из 1С в Excel,
                       и отправляет его в приложение.

   «Выгрузить меню»  — забирает из приложения меню на сегодня и кладёт
                       рядом файл для Excel: посмотреть или распечатать.

Настройки у них общие — один файл settings.txt.


Установка (один раз)
--------------------
1. Скопируйте всю эту папку на компьютер, например в
   C:\Загрузка меню

2. Откройте settings.txt Блокнотом и проверьте:
      server   — адрес сервера (обычно менять не нужно)
      login    — логин технолога столовой, тот же, что в приложении
      password — пароль

   Необязательно:
      folder        — папка, куда 1С выгружает меню. Если указать, окно
                      выбора файла будет сразу открываться в ней.
      export_folder — куда «Выгрузить меню» кладёт файл. Пусто — рядом
                      со скриптом.

3. Для удобства сделайте ярлыки на рабочем столе — правой кнопкой по файлу →
   «Отправить» → «Рабочий стол (создать ярлык)»:

      «Загрузить меню.bat»
      «Выгрузить меню.bat»


Как пользоваться
----------------
После выгрузки меню из 1С — одно действие:

   перетащите файл Excel на ярлык «Загрузить меню»

Либо запустите ярлык двойным щелчком и выберите файл в открывшемся окне.

Через несколько секунд появится сообщение, например:

   Загружено:
   28.07.2026 — 12 блюд (Супы 3, Вторые блюда 5, Напитки 4)

Проверьте по нему, что всё распозналось верно. Меню сразу видно в приложении
в разделе «Меню».


Выгрузка меню на сегодня
------------------------
Запустите ярлык «Выгрузить меню» двойным щелчком. Через несколько секунд
появится сообщение, например:

   Выгружено:
   19.08.2026 — 12 блюд (Супы 3, Вторые блюда 5, Напитки 4)
   Файл: C:\Загрузка меню\Меню 2026-08-19.csv

и файл сам откроется в Excel. Столбцы: раздел, блюдо, порция, цена.

Нужен не сегодняшний день — запустите с датой из командной строки:

   "Выгрузить меню.bat" 2026-08-20

Дата пишется как ГГГГ-ММ-ДД.

Если на этот день меню в приложении ещё нет, программа так и скажет и файл
создавать не будет.

По умолчанию файл кладётся рядом со скриптом. Чтобы складывать в другое
место — впишите путь в settings.txt в поле export_folder.


Что важно знать
---------------
• Повторная загрузка того же дня заменяет меню целиком, а не добавляет второй
  раз. Ошиблись файлом — просто загрузите правильный.

• Если в файле несколько дат, каждый день запишется отдельно.

• Разделы («Супы», «Вторые блюда», «Напитки») берутся из строк без цены.
  Если в выгрузке разделов нет, все блюда попадут в раздел «Блюда».

• Поправить отдельное блюдо можно прямо в приложении: «Меню» → значок
  календаря с карандашом.

• Первая загрузка за день может идти до минуты — сервер «просыпается».


Если что-то пошло не так
------------------------
Рядом со скриптами ведётся общий журнал upload_log.txt — в него пишется
каждый запуск обеих программ: какой файл, какой адрес, что ответил сервер,
текст ошибки. Откройте его в первую очередь.

Если окно вообще не появилось, запустите вручную и посмотрите сообщение:

   1. Откройте папку со скриптом
   2. Зажмите Shift, правой кнопкой в пустом месте -> "Открыть окно
      PowerShell здесь"
   3. Выполните:
        powershell -ExecutionPolicy Bypass -File .\upload_menu.ps1

Программа показывает причину прямо в окне:

  «Неверный логин или пароль» — проверьте settings.txt.

  «Загружать меню может технолог столовой» — указан чужой логин.

  «В файле не найдено ни одного блюда» — скорее всего выбран не тот файл,
  либо 1С изменила разметку выгрузки. Пришлите этот файл разработчику,
  разбор поправят на сервере — программу на вашем компьютере обновлять
  не придётся.
