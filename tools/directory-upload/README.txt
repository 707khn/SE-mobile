СПРАВОЧНИК ПРЕДПРИЯТИЯ В ПРИЛОЖЕНИИ
====================================

Что это
-------
Маленькая программа для компьютера администратора. Берёт файл справочника
в Excel — тот самый, что рассылают по предприятию, — и отправляет его в
приложение. Устанавливать ничего не нужно: работает на встроенном в
Windows PowerShell.

После загрузки справочник виден всем сотрудникам в приложении: раздел
«Справочник» в боковом меню. Оттуда можно позвонить по внутреннему номеру
или на мобильный и написать на почту — одним касанием.


Установка (один раз)
--------------------
1. Скопируйте всю эту папку на компьютер, например в
   C:\Справочник

2. Откройте settings.txt Блокнотом и заполните:
      server   — адрес сервера (обычно менять не нужно)
      login    — логин администратора, тот же, что в приложении
      password — пароль

   Необязательно:
      folder   — папка, где лежит файл справочника. Если указать, окно
                 выбора файла будет открываться сразу в ней.

3. Сделайте ярлык файла «Загрузить справочник.bat» на рабочем столе:
   правой кнопкой по файлу → «Отправить» → «Рабочий стол (создать ярлык)».


Как пользоваться
----------------
Когда справочник обновили — одно действие:

   перетащите файл Excel на ярлык «Загрузить справочник»

Либо запустите ярлык двойным щелчком и выберите файл в открывшемся окне.

Через несколько секунд появится сообщение, например:

   Загружено: 129 записей, 28 подразделений

Проверьте по нему, что всё распозналось. Справочник в приложении обновится
у всех сразу — пересобирать и раздавать ничего не нужно.


Что важно знать
---------------
• Загрузка заменяет справочник целиком, а не дополняет. Так уволенные
  исчезают сами; иначе они оставались бы в нём навсегда.

• Отделы берутся из строк, где заполнено только название и больше ничего —
  ровно как в печатном справочнике. Всё, что идёт под такой строкой,
  попадает в этот отдел.

• ФИО ищется в любом столбце левее должности: в файле имена стоят то в
  первом столбце, то во втором, и это нормально.

• Записи без человека — «КПП», «Электроцех» — загружаются наравне с
  остальными: звонят туда так же.

• Тот, кто указан дважды в разных ролях, и в приложении будет дважды —
  как в файле.

• Загружать справочник может только администратор. У технолога столовой,
  который грузит меню, прав на это нет.


Если что-то пошло не так
------------------------
Рядом со скриптом ведётся журнал upload_log.txt — в него пишется каждый
запуск: какой файл, какой адрес, что ответил сервер и полная причина
ошибки. Откройте его в первую очередь.

Программа показывает причину прямо в окне:

  «Неверный логин или пароль» — проверьте settings.txt.

  «Загружать справочник может администратор» — указан чужой логин.

  «В файле не найдено ни одной записи» — скорее всего выбран не тот файл
  либо в нём нет строки заголовков со словами «ФИО» и «Должность».
  Пришлите файл разработчику: разбор поправят на сервере, а программу на
  вашем компьютере обновлять не придётся.

  «Невозможно разрешить удаленное имя» — компьютер не знает адреса
  сервера. Нужна запись api в внутренней зоне DNS предприятия,
  см. deploy/README.md, шаг 4.
