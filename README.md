# SE-Mobile

Мобильное приложение для учёта посещаемости и управления отчётами сотрудников компании **Semey Engineering (SE-BTRZ)**.

---

## Описание

**SE-Mobile** — кроссплатформенное мобильное приложение, разработанное на Flutter, предназначенное для удобного просмотра и выгрузки отчётов о посещаемости (истории проходов) сотрудников предприятия. Приложение обеспечивает разграниченный доступ в зависимости от роли пользователя: рядовые сотрудники видят только собственные данные, руководители — данные по всем подчинённым.

---

## Основные возможности

- **Авторизация** — вход по уникальному ключу сотрудника с сохранением сессии на устройстве
- **Ролевой доступ** — автоматическое определение роли (сотрудник / руководитель) по должности
- **Просмотр истории проходов** — отображение записей о посещаемости в виде таблицы
- **Фильтрация по датам** — выбор произвольного временного диапазона для отчёта
- **Экспорт отчётов** — формирование и сохранение файлов в форматах Excel (.xlsx) и CSV (.csv)
- **Справочник сотрудников** — просмотр и поиск по списку сотрудников (для руководителей)
- **Мультиязычность** — поддержка казахского (KZ) и русского (RU) языков
- **Интеграция с соцсетями** — быстрый переход на страницы компании в YouTube, Instagram, Facebook

---

## Роли пользователей

| Роль | Доступ |
|------|--------|
| Сотрудник | Просмотр и выгрузка собственных отчётов о посещаемости |
| Руководитель / Начальник / Директор | Просмотр отчётов по всем сотрудникам, справочник сотрудников |

## Технологический стек

- **Язык**: Dart
- **Фреймворк**: Flutter (stable)
- **Управление состоянием и навигация**: GetX
- **Локальное хранилище**: SharedPreferences
- **HTTP-запросы**: http
- **Генерация Excel**: excel
- **Генерация CSV**: csv
- **Шаринг файлов**: share_plus
- **Интернационализация**: intl, flutter_localizations
- **Платформы**: Android, iOS

## API

Бэкенд: `http://cp.se-btrz.com`

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| POST | `/login` | Авторизация пользователя |
| POST | `/report` | Все записи о посещаемости |
| POST | `/reportdate` | Записи за заданный период |
| POST | `/director_report` | Отчёты по сотруднику (для руководителей) |
| POST | `/get_sname` | Список сотрудников / поиск по ИИН |
